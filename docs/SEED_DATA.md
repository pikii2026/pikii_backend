# 마스터 데이터 시딩 가이드

프론트엔드 드롭다운에서 사용하는 기준 데이터(Master Table)를 DB에 넣기 위한 SQL 모음이다.
이 데이터가 없으면 프로필 생성 / 공고 생성 / 지원하기가 동작하지 않는다.

## 실행 방법

Railway 대시보드 → **MySQL 서비스 → Data 탭 → Query**에 아래 SQL을 붙여넣어 실행한다.
(또는 MySQL 서비스 Variables의 `MYSQL_PUBLIC_URL`로 DBeaver·IntelliJ 등에서 접속해 실행)

### 주의사항

- **한 번에 하나의 INSERT 문씩** 실행한다. Railway 쿼리 편집기는 입력 길이에 제한이 있어,
  긴 문장을 한 번에 붙여넣으면 중간에서 잘려 `You have an error in your SQL syntax` 오류가 난다.
  (대학교 목록을 4개로 나눠 둔 이유)
- 재실행하면 데이터가 중복되므로, 다시 넣을 때는 해당 테이블을 먼저 비운다.
  ```sql
  DELETE FROM apply_keyword;
  DELETE FROM apply_keyword_category;
  ```
- 마스터 조회 API에는 인메모리 캐시가 걸려 있다. 시딩을 마친 뒤 **앱 서비스를 한 번 재시작**해야
  `GET /api/v1/categories` 등에 반영된다.

## 대상 테이블

| 테이블 | 건수 | 대응 API |
|:--|--:|:--|
| `category` | 3 | `GET /categories` |
| `topic` | 14 | `GET /topics` |
| `tech_stack` | 66 | `GET /tech-stacks` |
| `keyword` | 18 | `GET /keywords` |
| `link_category` | 4 | `GET /link-categories` |
| `apply_keyword_category` + `apply_keyword` | 6 + 33 | `GET /apply-keywords` |
| `univ` | 389 | `GET /universities` |

> `license`(자격증)는 종류가 너무 많아 마스터로 관리하지 않는다.
> 사용자가 입력한 이름이 마스터에 없으면 자동 등록되도록 `ResumeService`에서 처리한다.

## 6. LinkCategory (외부 링크 플랫폼, 4개)

```sql
INSERT INTO link_category (name, pic_url) VALUES
    ('Git', NULL),
    ('Notion', NULL),
    ('LinkedIn', NULL),
    ('홈페이지', NULL);
```
